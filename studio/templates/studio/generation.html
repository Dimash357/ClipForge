Озвучка

Рекомендуемые модели для RTX 4060 Laptop 8 ГБ и установка
  1. ComfyUI: скачайте портативную сборку для Windows/NVIDIA с github.com/comfyanonymous/ComfyUI/releases, распакуйте, запустите run_nvidia_gpu.bat (адрес по умолчанию http://127.0.0.1:8188).
  2. Checkpoint: положите файл модели в ComfyUI\models\checkpoints\, нажмите «Проверить снова» и выберите его выше. Для 8 ГБ: одна SDXL-модель или одна SD 1.5 — не обе сразу.
  3. IP-Adapter (необязательно): в ComfyUI Manager установите «ComfyUI_IPAdapter_plus», веса — в models\ipadapter\, CLIP Vision — в models\clip_vision\ (имена файлов — в README пакета).
  4. Piper: в папке ClipForge выполните env\Scripts\python -m pip install piper-tts; голоса (.onnx + .onnx.json) с huggingface.co/rhasspy/piper-voices положите в папку голосов (по умолчанию models\piper).
  5. Или любой локальный TTS-сервер с OpenAI API (Kokoro-FastAPI, openedai-speech): укажите адрес, модель и голоса.
  6. Генерация идёт задачами в «Очереди задач»; ComfyUI освобождает VRAM после партии кадров, локальная LLM выгружается перед генерацией.
