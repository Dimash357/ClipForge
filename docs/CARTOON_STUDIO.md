# 3D — Cartoon Studio (MVP)

Одна идея → готовый MP4. Единый интерфейс для мультфильмов, Faceless Shorts, историй и обучающих видео
(`/studio/`). Всё локально, платных API нет. Этап, который не может дать реальный результат, останавливается с
причиной — заглушки не подставляются.

## Pipeline

| Этап | Компонент | Готово, когда |
|---|---|---|
| Сценарий | 3A `scripts.generate` (LLM с арендой VRAM, иначе шаблон) | есть сцены |
| Раскадровка | 3B `storyboard.build` | кадры есть, сцены не устарели, формат кадра совпадает |
| Изображения | 3C `genmedia.gen_images` (ComfyUI) | у каждого кадра валидное изображение |
| Озвучка | 3C `genmedia.gen_voices` (Piper / локальный TTS) + точные тайминги | все реплики озвучены (или озвучка выключена) |
| Монтаж | `production.assemble` → Timeline IR (1A) | `assembly_key` совпадает с текущими данными |
| Экспорт MP4 | 1B `timeline.renderer.render` (кэш сцен, NVENC) | файл есть и собран из текущего монтажа |
| Название и описание | LLM или локально по сценарию | есть заголовок |

Весь pipeline — одна задача очереди `production` (1C, ресурс `heavy`). Статус этапа вычисляется из документа
сценария, поэтому:

* **Возобновление:** после отмены, падения или перезапуска «Продолжить» пропускает готовые этапы; изображения и
  реплики сохраняются по одной, недоделанный элемент повторяется.
* **Частичная правка:** перегенерация кадра / реплики (или замена своим файлом в «Раскадровке») делает устаревшими
  только монтаж и экспорт; рендерер берёт неизменённые сцены из кэша и перерендеривает только затронутые.
  Изменение музыки или громкости — только финальное сведение.
* **One Click** — все этапы подряд. **Пошагово** — сначала только сценарий, дальше кнопки «Запустить» / «Переделать»
  у каждого этапа; редактирование сценария и кадров — на существующих страницах 3A/3B.

## Монтаж

* Холст: 9:16 (1080×1920 / 720×1280), 16:9 (1920×1080 / 1280×720), 1:1 (1080 / 720). Изображения генерируются в
  родном размере модели под этот формат (SDXL 768×1344 / 1344×768 / 1024×1024), промпты получают нужную подачу кадра.
* Камера: движения из раскадровки (push-in, pan, tilt), на статичных кадрах — мягкий Ken Burns; «Активные» усиливают.
* Переходы: плавные наплывы (0.35 с внутри сцены, 0.6 с между сценами), динамичные (склейки + короткий наплыв), склейки.
* Субтитры: слова из выравнивания озвучки (3C), размер под холст; текст на экране переносится и вписывается в кадр.
* Звук: озвучка, фоновая музыка с ducking под голос, эффекты — whoosh на смене сцен, impact на кульминации,
  pop на тексте, chime в финале; файл из папки SFX, если имя совпадает с пометкой сцены.
* Музыка: «Авто» — трек из папки музыки (слово настроения в имени файла — приоритет), иначе синтез ffmpeg
  (аккорды + арпеджио по настроению: playful / calm / emotional / tense / epic).

Результат: `media/generated/scripts/<id>/export/video_<формат>_<разрешение>p.mp4` и рядом `.txt` с названием,
описанием и хештегами; `timeline.json` — собранный Timeline IR.

## API

`POST /api/studio/create/` · `GET /api/studio/<id>/` · `POST /api/studio/<id>/run/ {only?, until?, force?}` ·
`POST /api/studio/<id>/settings/` · `POST /api/studio/<id>/meta/`; отдельные кадры / реплики —
`POST /api/scripts/<id>/media/ {what: frames|lines, ids, force}` (3C). Отмена — очередь задач.

## Производительность (RTX 4060 Laptop 8 GB, ориентиры)

* 45-секундный ролик ≈ 15–20 кадров: SDXL ≈ 10–25 с на кадр, SD 1.5 быстрее; Piper — секунды на реплику на CPU.
* Рендер 1080p с NVENC — обычно быстрее реального времени; 720p заметно быстрее.
* Модели грузятся по очереди: LLM выгружается перед ComfyUI, ComfyUI освобождает VRAM после партии (планировщик 1D).

## Проверка

```bat
env\Scripts\python manage.py test studio.tests.test_production
```
Сквозной тест: шаблонный сценарий, раскадровка, изображения и голоса от локального тестового двойника
ComfyUI/TTS, настоящий монтаж и рендер ffmpeg → MP4 (размер, звук, длительность), повторный запуск без
перегенерации, перегенерация одного кадра → перерендер одной сцены, отмена и продолжение, 16:9 и 1:1, музыка из
папки, честные ошибки, API и страницы.

## Ограничения

* «Мультфильм» — анимированные кадры (камера, переходы), не покадровая анимация персонажей и не img2video.
* Синтезированная музыка простая; для качества используйте свою папку музыки.
* Без LLM сценарий и описание — шаблонные (это видно в статусе этапа).
* Качество изображений и голосов определяется выбранными моделями; в среде разработки проверено на тестовом двойнике.
