# Clip Selection Studio (2D)

Страница `/projects/<id>/studio/` (кнопка «▦ Clip Studio» на странице проекта). Код: `studio/clipstudio.py`,
`static/studio/clipstudio.js`, `templates/studio/clipstudio.html`. Собирает существующие модули в одном месте —
анализ, Hook Engine, Smart Editing, Viral Director, рендер и очередь не дублируются.

## Что есть
* **Карточки** 9:16: видео (проигрывается при наведении, клик — звук), Viral Score, Hook Score, место в рейтинге,
  пометка «дубль», длительность итогового клипа, статус, раскладка, монтаж, вид начала.
* **Сортировка** (Viral, Hook, порядок, длительность, оценка момента), **фильтры** (готовые, в работе, ошибки,
  без дублей, топ Viral ≥ 60), **поиск**, **массовый выбор** («все» по текущему фильтру).
* **Сравнение** 2–4 клипов: видео рядом и таблица (Viral по частям, Hook, длительность, монтаж, начало, раскладка;
  лучшее значение подсвечено).
* **Единый редактор**: Границы (числа, ±1 с, «начало/конец = позиция» по исходнику, «найденные границы»),
  Hook (варианты с оценками), Монтаж (режимы и вырезки с галочками), Раскладка (режим, фон, вебка, переходы),
  Субтитры (вкл/выкл, стиль, шрифт, слов на экране, подсветка, цензура).
* **Предпросмотр итогового монтажа без полного рендера**: черновик 360×640, 24 fps, низкое качество, одна проходка
  нормализации громкости — тот же путь Timeline IR (раскладка, субтитры, тизер, вырезки); кэшируется по настройкам
  (`media/previews/<clip>/`, хранятся 6 последних). Клип и его рендер не меняются, задача в очередь не ставится.
* **Отмена**: «Шаг назад» и «Сбросить правки» — для неприменённых изменений; «Прошлая версия» — вернуть состояние до
  последнего применения (история 10 шагов); «Оригинал» — найденные границы, без Hook, монтажа и своих настроек.
* **Применение**: одно или несколько изменений → одна задача `render` в очереди (GPU Scheduler распределяет
  NVENC/NVDEC как обычно). «Применить лучшее» — лучшая комбинация Viral Director для всех выбранных клипов одной задачей.
* **Экспорт ZIP** выбранных готовых клипов: `NN_название.mp4`, `NN_название.txt` (название, описание, хештеги —
  текст Shorts, если сгенерирован, иначе метаданные клипа) и `shorts.csv` (UTF-8 для Excel). Хранится только
  последний экспорт проекта (`media/exports/`).
* **Состояние**: строка статуса проекта, живой прогресс задачи (операции, время, CPU/GPU), ошибки клипов и ошибки
  применения монтажа, ссылка на «Очередь задач».

## API
| | |
|---|---|
| `POST /api/clips/<id>/preview/` | черновик для неприменённых изменений → `{url, info}` |
| `POST /api/projects/<id>/apply/` | `{clips: [{id, start, end, mode, overrides, hook, edit}]}` → одна задача рендера |
| `POST /api/clips/<id>/restore/` | `{to: previous \| original}` |
| `GET /api/projects/<id>/export/?ids=1,2` | ZIP (пусто — все готовые) |

Состояние клипа хранится там же, где раньше (границы, `render_info.opts/mode`, `meta.hooks.selected`, `meta.edit`);
история и оригинал — в `meta.history` / `meta.original`. Старая страница проекта работает как прежде.
