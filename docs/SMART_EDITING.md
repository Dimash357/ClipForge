# Smart Editing (2B)

Код: `studio/smartedit.py` (план и перенос в Timeline IR), `pipeline._clip_edits` (встраивание),
`GET/POST /api/clips/<id>/edit/`, блок «Монтаж» в карточке клипа, настройка «Умный монтаж» в форме проекта.

## Что вырезается
| | Natural | Dynamic | Aggressive |
|---|---|---|---|
| Паузы длиннее | 1,1 с → 0,45 с | 0,6 с → 0,25 с | 0,4 с → 0,15 с |
| Эмоциональная пауза остаётся | 0,9 с | 0,6 с | 0,45 с |
| Повторы и перезапуски («я я я», «это было это было») | — | ✓ (остаётся последний дубль) | ✓ |
| Одиночные «э», «эм», «мм» | — | ✓ | ✓ |
| Малоинтересные фразы | — | — | ✓ |
| Приближение на склейках / толчок на реакции | — / 5 % | 8 % / 7 % | 12 % / 8 % |

Защищено всегда:
* паузы с реакциями — смех, крик, ликование, взрыв, выстрел, громкий голос, резкий звук (YAMNet + профиль громкости) — это не тишина;
* эмоциональные паузы: после вопроса, перед репликой с реакцией или эмоцией, перед главным моментом;
* главный момент клипа (payoff), 6 с подводки к нему и 3 с после;
* первая и последняя фраза, фразы с вопросами, цепляющими или эмоциональными словами, событиями на экране;
* слова: склейки только в паузах между словами, вокруг слов остаётся 60 мс;
* длина: клип не становится короче 85 % минимальной длины проекта (лишние вырезки помечаются «клип стал бы короче минимума»).

Камера: склейки внутри одного плана маскируются чередованием лёгкого приближения, на реакции — один плавный
толчок (ease-out 0,45 с), не чаще раза в 5 с. На раскладках с вебкой (game_cam, reaction_cam) эффектов нет. Смена
сцены исходного монтажа сохраняет своё затухание, если её не вырезали.

## Синхронизация
`to_timeline()` строит из плана Timeline IR: видеокуски с раскладкой своей сцены (траектория кропа сдвигается
к началу куска), звук из тех же кусков (12 мс затухания против щелчков, одна общая нормализация громкости на
весь клип), субтитры — каждое слово переносится на новое время. Рендерит Timeline Renderer (1B).

## Режимы и ручное управление
* Проект: `smart_edit` = `off` (по умолчанию, как раньше) | `natural` | `dynamic` | `aggressive`.
* Клип: блок «Монтаж» — переключение режимов с мгновенной оценкой (было → стало, вырезано по причинам), полоса
  «оставлено/вырезано», список вырезок с галочками (снять — оставить фрагмент), «▶ Предпросмотр» — исходник
  проигрывается с перескоком через вырезанное, «Применить» — перерендер в очереди, «Оригинал» — возврат без вырезок.

## Связь с другими модулями
* Hook Engine: тизер ставится после монтажа (берётся из исходника, даже если момент вырезан); выбор начала
  (`start`) сначала меняет границы клипа, потом строится план. Монтаж и тизер — один рендер.
* Очередь задач: применение — задача `render`; GPU Scheduler: NVENC/NVDEC через Timeline Renderer.
* Данные: транскрипт, кэш `audio.npz` / `sound.npz` / `screen.npz`; новых моделей нет.
