# AI Hook Engine (2A)

Код: `studio/hooks.py`; встраивание: `pipeline._find_hooks`, `pipeline._apply_teaser`; API `GET/POST /api/clips/<id>/hooks/`;
интерфейс — блок «Hook» в карточке клипа.

## Варианты начала
| Вид | Что делает | Смысл не теряется, потому что |
|---|---|---|
| `original` | клип как выбрал ранжировщик моментов | — |
| `start` | начало с другой фразы: позже (пропустить вялое начало) или до 4 с раньше (подтянуть сильную фразу) | только начала предложений; конец не меняется; длина в пределах проекта; главный момент клипа (payoff) не отрезается; обрезается не больше 45 % |
| `teaser` | «холодное открытие»: пик 1–3 с из клипа (смех, крик, восклицание, экран поражения…) играет первым, затем весь клип | клип остаётся целиком; тизер режется по паузам между словами |

## Hook Score 0–100 (первые 3 с варианта)
* **Речь, 35** — цепляющие слова, вопрос, реакции стримера (`moments.CUES`), эмоции, числа, темп; минус — тишина
  в начале и начало со связки/местоимения («ну», «и», «он»…), звучащее как продолжение.
* **Эмоции, 25** — возбуждение голоса относительно остального клипа (аудиопрофиль) и звуковые события YAMNet.
* **Динамика, 20** — события экрана (вспышка, смена сцены, экран поражения) и движение в кадре.
* **Связность, 20** — начало фразы, сохранение главного момента, целые слова в тизере.

Каждый вариант хранит части оценки и причины (`+9 вопрос`, `−10 начинается с «ну»…`). Рекомендуется вариант,
который лучше исходного минимум на 6 баллов, иначе остаётся исходный.

## Данные и производительность
Используется то, что пайплайн уже посчитал: транскрипт, кэш `audio.npz` + `sound.npz` (YAMNet), `screen.npz`,
профиль движения кандидатов из ранжировщика. Досчитываются только непокрытые окна (≤ 30 с выборки кадров,
через NVDEC/CPU планировщика ресурсов). Новых моделей и зависимостей нет.

## Режимы (`options.hook_engine`)
* `suggest` (по умолчанию) — варианты считаются и показываются, клип не меняется;
* `auto` — рекомендованный вариант применяется сразу;
* `off` — выключено.

## Применение
* `start` — клип перерендеривается с новыми границами (задача `render` в очереди).
* `teaser` — снимок клипа в Timeline IR + `hooks.prepend_teaser()` (новая сцена `hook`: та же раскладка кадра, звук
  с той же нормализацией громкости, субтитры момента) → Timeline Renderer (1B). Ошибка → клип остаётся без
  тизера, причина в `render_info.hook.error`.
* Ручной выбор: «Hook» в карточке клипа → «Предпросмотр» (участок исходника) → «Выбрать и перемонтировать».
