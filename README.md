# ClipForge Local v5 — локальная AI-студия коротких видео

Длинное видео → вертикальные Shorts / Reels / TikTok. Всё считается на вашем ПК, платные API не нужны.
v5 — это **расширение v4**: старые режимы, YouTube-получение исходника, faster-whisper и FFmpeg-рендер сохранены
и используются как резервные.

## Быстрый старт (Windows)

1. Python **3.10–3.12** (галочка *Add python.exe to PATH*) и **FFmpeg** — полная сборка с `ffmpeg`, `ffprobe`
   и фильтром `ass` (libass), например `ffmpeg-release-full` с gyan.dev.
   FFmpeg можно добавить в `PATH` **или** просто положить в папку проекта как `ffmpeg\bin\ffmpeg.exe` — скрипты найдут её сами.
2. Двойной клик `setup.bat`. Он работает **только с виртуальным окружением `env`** в папке проекта:
   использует существующее `env` или создаёт новое, ставит туда зависимости, проверяет FFmpeg и библиотеки,
   делает резервную копию базы в `backups\` и выполняет миграции. В системный Python ничего не устанавливается.
3. `start.bat` → проверка окружения → откроется http://127.0.0.1:8000
4. Видеокарта NVIDIA (необязательно): `install_gpu.bat` — библиотеки CUDA 12 для Whisper в `env`.
5. `diagnose.bat` (или страница **Система**) — FFmpeg, CUDA, NVENC, версии библиотек, конфликты `pip check`.
5. `run_tests.bat` — автотесты (тесты работают на временной базе и не трогают `db.sqlite3`).

Первая транскрибация скачает модель Whisper (нужен интернет один раз).

**Своё окружение в другой папке:** `set CLIPFORGE_ENV=C:\путь\к\env` перед запуском `.bat`.

**NumPy:** если в `env` уже стоит NumPy, `setup.bat` её **не обновляет** (например, `ultralytics` требует `numpy<2`) —
pip подберёт совместимые OpenCV и остальные пакеты. Проверено на Python 3.10.11 с NumPy 1.26 и NumPy 2.x.
Разрешить обновление NumPy: `set CLIPFORGE_ALLOW_NUMPY_UPGRADE=1`, затем `setup.bat` из того же окна.

**Если что-то не так** — каждый шаг печатает `[OK]` / `[!]` / `[X]` с причиной и способом исправления; при ошибке
скрипт останавливается до миграций, данные не меняются. Проекты, видео и база (`db.sqlite3`, `media\`,
`source_library\`) скриптами никогда не удаляются.

### Перенос данных из v4
Скопируйте из папки v4 в папку v5 файл `db.sqlite3` и папки `media/`, `source_library/`, затем `setup.bat`/`python manage.py migrate`.
Миграция `0003` только **добавляет** поля с значениями по умолчанию, старые проекты и клипы остаются (проверено тестом).
Для отката просто запустите прежнюю папку v4 со своей копией базы — v5 ничего в ней не меняет. Перед переносом сделайте копию `db.sqlite3`.

## Content Factory: видео из одной идеи (Cartoon Studio)

Вкладка **Cartoon Studio**: идея → сценарий → раскадровка → изображения → озвучка → монтаж → MP4 + название,
описание и хештеги. Форматы: мультфильм, Faceless Shorts, история, обучающее видео; кадр 9:16 / 16:9 / 1:1,
720p / 1080p. Режимы **One Click** и **пошагово** (каждый этап — отдельная кнопка, правка и перегенерация отдельных
кадров и реплик без пересборки всего проекта). Подробно: `docs/CARTOON_STUDIO.md`, генерация медиа — `docs/VISUAL_VOICE.md`.

Что нужно установить (всё бесплатно и локально, модели вручную — ClipForge их не скачивает):

1. **LLM для сценария** (необязательно): Ollama или LM Studio. Без модели сценарий строится по шаблону, и это видно в статусе.
2. **ComfyUI** (изображения): портативная сборка для NVIDIA → `run_nvidia_gpu.bat`; модель SDXL (например Juggernaut XL)
   или SD 1.5 (DreamShaper 8) в `ComfyUI\models\checkpoints`. Для постоянной внешности героев — ComfyUI_IPAdapter_plus.
3. **Piper** (озвучка, CPU) в окружение проекта:
   ```bat
   env\Scripts\python -m pip install piper-tts
   ```
   голоса `.onnx` + `.onnx.json` (например `ru_RU-dmitri-medium`) с huggingface.co/rhasspy/piper-voices → `models\piper`.
4. **Генерация** → «Проверить снова», выбрать checkpoint и голоса → «Сохранить».
5. **Cartoon Studio** → идея → «One Click». Фоновая музыка — из вашей папки (поле «Папка музыки») или синтезируется локально.

Для RTX 4060 Laptop 8 ГБ: одна SDXL-модель (≈6.5 ГБ VRAM) или SD 1.5 (≈3.5 ГБ); LLM, ComfyUI и Whisper
загружаются по очереди (планировщик GPU), при нехватке памяти кадр повторяется в меньшем размере.

## v5.4: нейросети для лиц и звуков, шрифты, фильтр мата, быстрый Whisper

* **Лица — YuNet** (нейросеть OpenCV, 232 КБ, лежит в `studio/models`, работает на CPU ~12 мс/кадр). Находит лица,
  которые старый Haar пропускал: повёрнутые, в очках, в темноте, в маленькой вебке (от ~10 px). Даёт точки глаз —
  Reaction Priority ставит глаза на верхнюю треть по ним. Если модель не загрузится, автоматически используется
  Haar (`set CLIPFORGE_FACE_DETECTOR=haar` — принудительно).
* **Звуки — YAMNet** (AudioSet, 521 класс, 16 МБ, скачивается один раз в папку `models\` при `setup.bat` или первой
  обработке, проверка SHA-256). Распознаёт **смех, крики, взрывы, выстрелы, овации** и подтверждает/опровергает
  находки по громкости; около 15 с CPU на час звука, результат кэшируется. Проверено на реальных записях
  (ESC-50, LaughterScape): смех находится так же часто, как раньше, а ложных «смехов» на других звуках 1 из 40
  вместо 24 из 40; фейерверки распознаются как взрывы. Шаги и стук, похожие на удар, отсеиваются по
  «звукам-двойникам». Без модели (нет интернета) работают прежние эвристики громкости.
  Отключить: галочка в дополнительных настройках.
* **Субтитры:** шрифт — «По стилю», **Montserrat** (встроен, SIL OFL), Arial Black, Arial, Impact; галочка
  **«Скрывать мат звёздочками»** (Б***) — и в субтитрах, и в названии/описании Shorts. Транскрипт в базе не меняется,
  фильтр можно включать/выключать при перемонтаже.
* **Whisper на видеокарте NVIDIA:** нужны библиотеки CUDA 12 (cuBLAS, cuDNN 9). Если в окне сервера есть
  `cublas64_12.dll is not found` — запустите **`install_gpu.bat`**: он ставит их в `env` (~1.3 ГБ, систему не меняет).
  Без них ClipForge сразу работает на процессоре (медленнее), не тратя время на попытки GPU.
* **Whisper быстрее:** пакетный режим faster-whisper (`BatchedInferencePipeline`) включается сам на видеокарте
  (пакеты по 16, обычно в 2–4 раза быстрее). Настройка `set WHISPER_BATCH=0|8|16|...` (0 — выключить, число —
  включить и на CPU). Если пакетный режим не сработает (не хватит видеопамяти), распознавание продолжится обычным.
* **Длинные видео с YouTube:** лимит размера 8 ГБ (`CLIPFORGE_MAX_SOURCE_GB`), загрузка до 120 мин
  (`CLIPFORGE_DOWNLOAD_MINUTES`), файл без видеодорожки никогда не принимается. Для YouTube yt-dlp нужен
  JavaScript-движок: `winget install DenoLand.Deno` (или Node.js), иначе YouTube может отдать только звук.
  Журнал загрузки — `logs\ytdlp-<номер проекта>.log`.

## v5.3: AI Auto и названия для Shorts

**AI Auto** (режим по умолчанию в форме) выбирает режим монтажа **для каждого клипа отдельно** по уже сделанному
анализу клипа (тот же кэш, повторной обработки нет): формат исходника, вебка (в клипе и по всему видео), лица,
движение и его разброс, сцены, вшитые титры и оценки клипа (реакция, звук, динамика).
* вебка + сильная реакция стримера → **Reaction Priority**; вебка + активный геймплей → **Gameplay Priority**;
* в клипе меняются сцены (игра / лицо / экран) → **Auto Scene Director** (раскладка по сценам внутри клипа);
* лицо крупно → **Smart Reframe**; интерфейс/текст или вшитые титры → **Без обрезки**;
* игра без вебки: действие в одной области → весь вертикальный кадр со слежением; действие по всему экрану →
  **Gameplay** (весь кадр на фоне, HUD и края не обрезаются); вертикальный исходник → Smart Reframe.

В карточке клипа: «AI Auto → режим» и причина выбора. Любой режим можно выбрать вручную в «Перемонтировать».

**Название и описание для Shorts** — после рендера, для каждого клипа: одно название КАПСОМ с 1–3 эмодзи, короткое
описание и хештеги, кнопки «Скопировать название», «Скопировать описание», «Сгенерировать заново». Используются
речь клипа, речевые маркеры, события звука и экрана из кэша и раскладка клипа. Результат хранится в базе
(`Clip.meta.short`) и не пересоздаётся при открытии страницы или перемонтаже, если содержание клипа не изменилось.
* Имя стримера появляется только если вы указали его в поле «Стример в видео» или оно есть в названии/канале
  YouTube-видео и в списке `studio/data/streamers.txt` (его можно дополнять). Выдуманные имена и числа отбрасываются.
* **AI-провайдер (необязательно):** любой OpenAI-совместимый API или локальный Ollama.
  ```
  set CLIPFORGE_AI_URL=http://127.0.0.1:11434/v1      (Ollama / LM Studio / OpenAI / OpenRouter ...)
  set CLIPFORGE_AI_MODEL=qwen2.5:7b
  set CLIPFORGE_AI_KEY=...                            (только для облачных API)
  ```
  или `set USE_OLLAMA=1` (+ `OLLAMA_MODEL`). Ответ ИИ проверяется (капс, эмодзи, язык, без непроверенных имён и
  чисел); если он не прошёл проверку, API недоступен или отвечает дольше `CLIPFORGE_AI_TIMEOUT` (25 с), используется
  локальный генератор, а ИИ ставится на паузу 5 минут — рендер никогда не ждёт API. Статус — на странице «Система».
  Без настроек всё работает локально, без интернета.

## v5.2: автоматический монтаж стримов

**Порядок обработки:** 1) получение видео и проба (длительность, разрешение, FPS, звук) → вебка ищется по всему
ролику → 2) звук извлекается в mono 16 kHz WAV → 3) Whisper распознаёт этот WAV с таймкодами слов, язык
определяется автоматически → 4) кандидаты по речи, эмоциям в звуке и событиям на экране → 5) выбор лучших
неповторяющихся моментов → 6) монтаж через FFmpeg → 7) автопроверка видео, звука и субтитров.

**Поиск моментов** (оценка «Интересность» 0–100 у каждого клипа):
* речь: восклицания («ЧТО?!», «ДА ЛАДНО!», «ТЫ ВИДЕЛ?!»), мат (в т.ч. «звёздочки» Whisper), фейлы и смерти,
  провал миссии, донаты и подписки, разговор/спор с чатом, баги и абсурдные ситуации, смех в тексте;
* звук: крики, смех, повышенный голос, всплески громкости, драматические паузы (`audio_analysis.py`);
* экран: «экран смерти» (резкое затемнение, обесцвечивание, красная заливка), вспышки, смены сцен — по ключевым
  кадрам всего видео, плюс движение у лучших кандидатов (`motion_analysis.py`);
* сигналы, совпавшие по времени, объединяются (`moments.py`); момент, который подтверждают несколько источников,
  ценится выше, а просто громкий звук без подтверждения речью или картинкой — ниже;
* кроме фраз-кандидатов строятся окна вокруг событий: 1–3 с подготовки перед событием (виден повод, крючок в первые
  1–2 с), затем реакция и кульминация; границы не режут слова; повторы и скучные куски штрафуются.

**Длительность «Авто»** (по умолчанию в форме): каждый клип 12–60 с по содержанию момента, без фиксированной цели.

**Стиль клипа:** 1080×1920, 30 FPS (источник ниже 30 FPS не «растягивается»), H.264 + AAC 48 kHz,
громкость −14 LUFS двухпроходным loudnorm, true peak ≤ −1.5 dBTP (отключается: «Громкость → Как в исходнике»).
* **Reaction Priority** (новый режим): вебка сверху (40%), лицо по центру, глаза на верхней трети панели; игра снизу
  (60%) с удалением дубля вебки. Субтитры — на стыке панелей, не на лице и не на игре.
* **Gameplay Priority** = прежний Gameplay + Facecam (максимум игры, вебка внизу).
* Нет вебки (в Reaction и Gameplay Priority при «Авто») — игра на весь вертикальный кадр, кадр плавно следует за
  главным движением на экране (неподвижный HUD игнорируется). Если угол вебки указан вручную — используется он.

**Субтитры «Stream»** (стиль по умолчанию): по одному слову синхронно с речью, крупный жирный белый шрифт с чёрной
обводкой; ключевые слова (восклицания, мат, фейлы, эмоции, числа, главные слова клипа) — жёлтым. Текст берётся из
распознанной речи, поэтому язык субтитров совпадает с языком стрима.

**Сохранение анализа:** WAV, аудиопрофиль, скан экрана и анализ сцен каждого клипа лежат в `media/analysis/<отпечаток>/`
и переиспользуются: «Подобрать моменты заново» и перемонтаж клипа не декодируют звук и не анализируют сцены повторно.
Сводка (разрешение, язык, вебка) видна на странице проекта.

**Ручные границы:** в предпросмотре и в «Перемонтировать» — поля начала/конца, кнопки −1/+1 с, «из плеера»,
«↺ Найденные границы» и галочка «не резать слова» (граница сдвигается к краю ближайшего слова).

**Автопроверка** дополнительно проверяет формат (1080×1920, H.264/AAC, FPS) и громкость (≈ −14 LUFS, без клиппинга).

Ограничения: распознавание событий — эвристики. «Экран смерти» находится по цвету и яркости, поэтому игры без
затемнения/обесцвечивания при смерти дают только речевые и звуковые признаки; «абсурдные ситуации» распознаются по
речи стримера («что происходит», «это баг») и всплескам движения, а не по пониманию сцены.

## v5.1: Gameplay + Facecam и умный поиск хайлайтов

**Gameplay + Facecam** (и сцены «игра + вебка» в Director):
* Игра сохраняет пропорции и показывается крупнее: масштаб адаптивный, обрезка по бокам ограничена бюджетом
  (`Игра в Gameplay + Facecam`: *Баланс* до 16% ширины, *Вся картинка* 0%, *Крупно* до 30%); остаток панели — фон.
* Обрезка тратится в первую очередь со стороны вебки: если вебка помещается в бюджет, она просто отрезается кадрированием.
* Оставшаяся часть оверлея **восстанавливается из соседней области кадра** (два зеркальных отражения от внутренних
  краёв, смешанные по расстоянию — швы непрерывны, текстура игры сохраняется). Блюр не используется; старая
  пикселизация доступна опцией «Как убрать вебку из игры». Восстановить «настоящие» пиксели из других кадров нельзя:
  оверлей закрывает одну и ту же область всё время.
* Вебка — отдельная панель внизу (высота по пропорциям оверлея, 22–36% кадра), масштаб Lanczos + лёгкая резкость,
  рамка оверлея обрезается. Субтитры стоят над панелью камеры, игра прижата к верху своей панели.

**Поиск хайлайтов** (движок «Улучшенный»): итоговая оценка = текст (Hook/Context/Engagement/Completeness) + **звук** + **динамика**.
* Звук (`audio_analysis.py`): громкость относительно локального уровня речи, крики, смех (ритм коротких всплесков),
  повышенный голос (тон выше обычного), резкие всплески громкости, паузы и «драматическая пауза» перед взрывом эмоций.
  30 минут аудио анализируются примерно за 10 с.
* Динамика геймплея (`motion_analysis.py`): движение, резкие всплески движения, смены сцен, статичная картинка —
  считается только для ~12 лучших кандидатов (≤ 15 мин видео), чтобы не декодировать весь стрим.
* Границы: если реакция продолжается после последней фразы или пик в самом конце — конец продлевается; если клип
  открывается всплеском — добавляется 1–1.5 с «причины» перед ним. Слова при этом никогда не режутся.
* Скучное (ровная громкость + слабая речь) и повторяющееся («да да да…») получает штраф.
* Новые оценки «Звук/эмоции» и «Динамика» видны в карточках кандидатов, причины — в тексте «Выбран, потому что…».
* Любая ошибка анализа (нет аудиодорожки, битый файл, сбой декодера) → ранжирование только по тексту, как в v5.
  Отключается галочками в дополнительных настройках.

## GPU (RTX 4060)
* **NVENC**: включается автоматически только если тестовое кодирование прошло. Иначе CPU (`libx264`). Если NVENC упадёт во время рендера — клип будет пересчитан на CPU.
* **CUDA для Whisper**: для `faster-whisper` нужны драйвер NVIDIA и библиотеки CUDA 12 (cuBLAS) + cuDNN 9, доступные в `PATH`
  (см. раздел GPU в документации faster-whisper). Если их нет, ClipForge продолжит на CPU. Принудительно на CPU: `set WHISPER_DEVICE=cpu`.
* Версию PyAV (`av==16.1.0`) и зависимости транскрибации я не менял.

## Известные ограничения (честно)
* Детекция лиц — классический Haar (frontal). Профиль, очки, лица < ~25 px на 640-px кадре могут не находиться; для мелкой facecam укажите её угол вручную.
* Классификация сцен — эвристика (лица, статичность, однородность блоков), не нейросеть. На необычных видео возможны ошибки; для этого есть пороги уверенности, fallback и ручной режим.
* Оценки Hook/Context/Engagement — эвристики для сравнения фрагментов внутри одного видео, **не прогноз вирусности**.
* Названия — извлечение из речи, а не творческая генерация; без Ollama только на языке видео.
* Поиск вшитых титров — эвристика (яркие узкие строки из нескольких букв в нижней половине кадра). Титры без светлой заливки или очень мелкие могут не находиться; тогда выберите «Без обрезки» вручную.
* В режиме «Без обрезки» 16:9 занимает примерно треть высоты вертикального кадра: это цена показа всего изображения.
* Повёрнутые (rotation metadata) и HDR-исходники не обрабатывались отдельно.
* Cartoon Studio: «мультфильм» — это анимированные кадры (zoom/pan, наплывы), а не покадровая анимация персонажей; качество картинок и голосов зависит от выбранных моделей.
* Синтезированная фоновая музыка простая (аккорды + арпеджио); для лучшего звучания укажите папку своей музыки.
* Приложение только для локального использования. Используйте получение видео по ссылке лишь для материалов, на которые у вас есть права.
