# ClipForge Local v5 — локальная AI-студия коротких видео

Длинное видео → вертикальные Shorts / Reels / TikTok. Всё считается на вашем ПК, платные API не нужны.
v5 — это **расширение v4**: старые режимы, YouTube-получение исходника, faster-whisper и FFmpeg-рендер сохранены
и используются как резервные.

## Быстрый старт (Windows)

1. Python 3.12 (галочка *Add to PATH*) и **FFmpeg** (с `ffmpeg`, `ffprobe` и фильтром `ass`/libass) в `PATH`.
2. Распакуйте архив **в отдельную папку** (рядом с v4, не поверх).
3. Двойной клик `setup.bat` (создаёт `.venv`, ставит зависимости, делает миграции).
4. `start.bat` → откроется http://127.0.0.1:8000
5. Страница **Система** (или `diagnose.bat`) покажет, что найдено: FFmpeg, CUDA, NVENC, библиотеки.

Первая транскрибация скачает модель Whisper (нужен интернет один раз).

### Перенос данных из v4
Скопируйте из папки v4 в папку v5 файл `db.sqlite3` и папки `media/`, `source_library/`, затем `setup.bat`/`python manage.py migrate`.
Миграция `0003` только **добавляет** поля с значениями по умолчанию, старые проекты и клипы остаются (проверено тестом).
Для отката просто запустите прежнюю папку v4 со своей копией базы — v5 ничего в ней не меняет. Перед переносом сделайте копию `db.sqlite3`.

## Что нового

| Область | Что сделано |
|---|---|
| **Auto Scene Director** | Новый режим. Разбивает клип на сцены: *игра*, *автор крупно*, *игра + facecam*, *экран/интерфейс* и для каждой выбирает раскладку. Сглаживание (минимум сцены 3 с, мажоритарный фильтр), пороги уверенности, fallback на Gameplay/Smart, ручной выбор угла facecam, необязательный fade-переход 0.25 с |
| **Без обрезки (новый режим)** | Весь кадр целиком по центру на размытом фоне, ничего не режется по бокам. Для фильмов, интервью, видео с вшитыми титрами. Свои субтитры лежат на размытой полосе под картинкой |
| **Защита вшитых титров** | Если в исходнике есть свои титры/субтитры и кроп 9:16 их разрезал бы, Smart Reframe сам показывает кадр целиком (отключается галочкой «Не обрезать вшитые титры» в доп. настройках). Если титры найдены, клип получает подсказку отключить собственные субтитры, чтобы текст не дублировался |
| **Gameplay + Facecam (исправлен)** | Нет чёрных полос, игра целиком на размытом фоне, камера в нижней панели обрезается вокруг лица, дубль лица в игровой панели скрывается, субтитры стоят над панелью камеры |
| **Smart Reframe** | Плавная «виртуальная камера»: мёртвая зона, ограничение скорости, несколько лиц (кадрируются вместе, если помещаются), игнорирование лица facecam |
| **Highlights v2** | Границы по предложениям, оценки Hook / Context / Engagement / Completeness / Overall, причина выбора, защита от повторов. Старый алгоритм — автоматический fallback |
| **Субтитры** | 5 стилей (Clean, Bold Shorts, Gaming, Karaoke, Cinematic) + Classic (как в v4), замер ширины (не вылезают за кадр), подсветка слова только при надёжных таймкодах, позиция зависит от раскладки и safe-зон |
| **Метаданные** | 3–5 названий, описание, хештеги — только из речи клипа. Двуязычность — при `USE_OLLAMA=1` |
| **Контроль** | Предпросмотр найденных фрагментов и правка границ (опция «сначала показать»), повторный монтаж клипа с другими настройками, отмена, продолжение |
| **Автопроверка** | Длительность, синхронизация A/V, чёрные кадры, тишина, длина, субтитры, дубли — оценка 0–100 |
| **Экспорт** | 1080×1920 / 720×1280, качество, FPS (выше FPS исходника не поднимается), NVENC |
| **Надёжность** | Одна очередь задач (по умолчанию 1 тяжёлая задача), нет двойных воркеров при autoreload, восстановление зависших проектов, безопасная отмена (убивает ffmpeg/yt-dlp), нет дублей клипов, транскрипт и скачанное видео переиспользуются |
| **Интерфейс** | Новый тёмный ClipForge Studio: реальные этапы без фальшивых процентов, карточки клипов, история с фильтрами, страница диагностики |

## v5.1: Gameplay + Facecam и умный поиск хайлайтов

**Gameplay + Facecam** (и сцены «игра + вебка» в Director):
* Игра сохраняет пропорции и показывается крупнее: масштаб адаптивный, обрезка по бокам ограничена бюджетом
  (`Игра в Gameplay + Facecam`: *Баланс* до 16% ширины, *Вся картинка* 0%, *Крупно* до 30%); остаток панели — фон.
* Обрезка тратится в первую очередь со стороны вебки: если вебка помещается в бюджет, она просто отрезается кадрированием.
* Оставшаяся часть оверлея **восстанавливается из соседней области кадра** (два зеркальных отражения от внутренних
  краёв, смешанные по расстоянию — швы непрерывны, текстура игры сохраняется). Блюр не используется; старая
  пикселизация доступна опцией «Как убрать вебку из игры». Восстановить «настоящие» пиксели из других кадров нельзя:
  оверлей закрывает одну и ту же область всё время.
* Вебка — отдельная панель внизу (высота по пропорциям оверлея, 22–36% кадра), масштаб Lanczos + лёгкая резкость,
  рамка оверлея обрезается. Субтитры стоят над панелью камеры, игра прижата к верху своей панели.

**Поиск хайлайтов** (движок «Улучшенный»): итоговая оценка = текст (Hook/Context/Engagement/Completeness) + **звук** + **динамика**.
* Звук (`audio_analysis.py`): громкость относительно локального уровня речи, крики, смех (ритм коротких всплесков),
  повышенный голос (тон выше обычного), резкие всплески громкости, паузы и «драматическая пауза» перед взрывом эмоций.
  30 минут аудио анализируются примерно за 10 с.
* Динамика геймплея (`motion_analysis.py`): движение, резкие всплески движения, смены сцен, статичная картинка —
  считается только для ~12 лучших кандидатов (≤ 15 мин видео), чтобы не декодировать весь стрим.
* Границы: если реакция продолжается после последней фразы или пик в самом конце — конец продлевается; если клип
  открывается всплеском — добавляется 1–1.5 с «причины» перед ним. Слова при этом никогда не режутся.
* Скучное (ровная громкость + слабая речь) и повторяющееся («да да да…») получает штраф.
* Новые оценки «Звук/эмоции» и «Динамика» видны в карточках кандидатов, причины — в тексте «Выбран, потому что…».
* Любая ошибка анализа (нет аудиодорожки, битый файл, сбой декодера) → ранжирование только по тексту, как в v5.
  Отключается галочками в дополнительных настройках.

## Режимы монтажа
`Auto Scene Director` · `Smart Reframe` · `Gameplay + Facecam` · **`Без обрезки`** · `Gameplay` · `Центр` (все старые сохранены, «Без обрезки» добавлен).
Режим по умолчанию в форме — Smart Reframe, как в v4; Director выбирайте для видео, где автор переключается между игрой и лицом.

## Настройки среды (необязательно)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `WHISPER_MODEL` | `small` | `medium` точнее, но тяжелее |
| `WHISPER_DEVICE` | `auto` | `auto` (CUDA только если проба прошла, при ошибке — откат на CPU) · `cpu` · `cuda` (принудительно) |
| `WHISPER_COMPUTE` | по устройству | `int8` / `float16` / `int8_float16` |
| `CLIPFORGE_MAX_JOBS` | `1` | число одновременных тяжёлых задач |
| `USE_OLLAMA`, `OLLAMA_MODEL` | выкл. | необязательный перерейтинг и двуязычные названия |
| `CLIPFORGE_LOG_LEVEL` | `INFO` | логи в `logs/clipforge.log` |

## GPU (RTX 4060)
* **NVENC**: включается автоматически только если тестовое кодирование прошло. Иначе CPU (`libx264`). Если NVENC упадёт во время рендера — клип будет пересчитан на CPU.
* **CUDA для Whisper**: для `faster-whisper` нужны драйвер NVIDIA и библиотеки CUDA 12 (cuBLAS) + cuDNN 9, доступные в `PATH`
  (см. раздел GPU в документации faster-whisper). Если их нет, ClipForge продолжит на CPU. Принудительно на CPU: `set WHISPER_DEVICE=cpu`.
* Версию PyAV (`av==16.1.0`) и зависимости транскрибации я не менял.

## Автотесты
`run_tests.bat` (или `python manage.py test studio`). Полный прогон ≈ 4 минуты; `set CLIPFORGE_SKIP_SLOW=1` пропускает рендер-тесты.
Тесты генерируют синтетическое видео и не скачивают ничего, кроме dev-зависимости `scikit-image` (в ней лежит тестовое лицо).

## Структура новых модулей
`jobs.py` очередь/отмена/восстановление · `procutil.py` ffmpeg с прогрессом · `scenes.py` анализ сцен и трекинг ·
`layouts.py` filtergraph раскладок · `audio_analysis.py` / `motion_analysis.py` сигналы для хайлайтов · `editor.py` план + рендер клипа · `highlights.py` · `captions.py` · `metadata.py` ·
`quality.py` · `exports.py` пресеты и валидация настроек · `diagnostics.py` · `textutil.py`. Файл `pipeline.py` содержит **старый v4-код без изменений
логики** и новую оркестрацию внизу.

## Известные ограничения (честно)
* Детекция лиц — классический Haar (frontal). Профиль, очки, лица < ~25 px на 640-px кадре могут не находиться; для мелкой facecam укажите её угол вручную.
* Классификация сцен — эвристика (лица, статичность, однородность блоков), не нейросеть. На необычных видео возможны ошибки; для этого есть пороги уверенности, fallback и ручной режим.
* Оценки Hook/Context/Engagement — эвристики для сравнения фрагментов внутри одного видео, **не прогноз вирусности**.
* Названия — извлечение из речи, а не творческая генерация; без Ollama только на языке видео.
* Поиск вшитых титров — эвристика (яркие узкие строки из нескольких букв в нижней половине кадра). Титры без светлой заливки или очень мелкие могут не находиться; тогда выберите «Без обрезки» вручную.
* В режиме «Без обрезки» 16:9 занимает примерно треть высоты вертикального кадра: это цена показа всего изображения.
* Повёрнутые (rotation metadata) и HDR-исходники не обрабатывались отдельно.
* Приложение только для локального использования. Используйте получение видео по ссылке лишь для материалов, на которые у вас есть права.
